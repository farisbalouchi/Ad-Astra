# Ad-Astra
A website for a fictional global space exploration organization meant as a practice front-end project. *NO AI TOOLS WERE USED*
## What I learned
I learned how to write headers on top of images which is very simple but took me some fun trial and error to learn 
I learned how to put different lines of code for different sections in their own respective files and how to link them.
I learned more about how important code readability is and how important it is to be able to debug your own code when needed.
